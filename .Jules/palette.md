## 2025-05-23 - [Documentation Portability and Branding]
**Learning:** In technical SDK repositories, Developer Experience (DX) is the primary UX. Absolute GitHub URLs in documentation break navigation in forks or local checkouts. Using relative paths ensures a "it just works" experience for developers exploring the codebase.
**Action:** Always prefer relative paths for internal repository navigation in READMEs. Center branding logos (128px) at the top of main documentation files to provide instant visual context.
