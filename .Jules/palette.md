# Palette's Journal - UX & Accessibility Learnings

## 2026-06-22 - [Documentation DX & Branding]
**Learning:** In technical SDK repositories, Developer Experience (DX) is a critical part of UX. Ensuring that documentation snippets are not only visually pleasing (branding) but also functionally reliable (proper directives like `PublishAot=false`) and navigable in various environments (relative links) significantly reduces user friction.
**Action:** Always verify that standalone code samples contain necessary execution directives and use relative links for internal repository references to maintain context across forks.
