# Palette's Journal - UX & Accessibility Learnings

## 2025-05-15 - [Directives Syntax Consistency]
**Learning:** In technical SDK documentation, consistent and accurate metadata syntax (like the `#:property` directive) is a critical component of Developer Experience (DX). Incorrect troubleshooting guidance can lead to frustration and wasted time when users attempt to follow examples.
**Action:** Always verify that documentation troubleshooting steps align with the actual implementation and usage patterns found in the codebase.
