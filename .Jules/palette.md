## 2025-05-17 - [Branding and Navigation DX]
**Learning:** In technical SDK repositories without a web UI, UX improvements focus on Developer Experience (DX). Branding via a centered logo in the README improves repository identity, while relative navigation links ensure functional documentation across different environments (forks, branches, local checkouts).
**Action:** Prefer relative paths for internal documentation links; use centered HTML tags for repository logos to maintain a professional and accessible layout.
