# Palette Journal

## 2025-06-03 - Repository Branding and Documentation Accessibility
**Learning:** In technical SDK repositories without a web UI, UX improvements focus on Developer Experience (DX). Centered branding and descriptive alt-text for repository logos improve visual hierarchy and accessibility for documentation readers.
**Action:** Always include centered branding with `alt` text in major documentation READMEs to improve the repository's professional feel and accessibility.
