## 2025-05-15 - Branding and Navigation Consistency
**Learning:** In a technical SDK repository, Developer Experience (DX) is the primary UX. Providing immediate visual identity (branding) and ensuring that documentation links work reliably across various environments (relative vs absolute) significantly lowers the cognitive load for developers.
**Action:** Always center repository branding in the root README and prefer relative paths for in-repo documentation to maintain functionality in forks and branches.
