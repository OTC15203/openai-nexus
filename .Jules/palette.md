## 2025-05-14 - [Documentation Branding and Navigation]
**Learning:** For technical SDK repositories, Developer Experience (DX) is improved by consistent branding and relative navigation. Using centered logos and `./` prefixed relative links in READMEs ensures a professional appearance and functional navigation across different environments (IDE, local clone, GitHub).
**Action:** Always center the repository logo (e.g., `eng/OpenAI.png`) at the top of README files and prefer `./` prefixed relative links for internal repository navigation.
