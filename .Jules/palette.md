# Palette's Journal - UX & Accessibility Learnings
## 2025-05-14 - Branding and Snippet DX
**Learning:** Developer Experience (DX) for technical documentation is a core component of UX in this repository; ensuring C# snippets have consistent configuration (e.g., PublishAot=false) and accurate metadata syntax prevents runtime failures for users. Repository branding with descriptive alt-text also provides a consistent and accessible first-run experience.
**Action:** Always verify snippet metadata against repository standards and test execution before submitting documentation changes. Ensure standard branding assets (eng/OpenAI.png) are used in documentation roots.
