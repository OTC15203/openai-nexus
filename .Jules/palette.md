## 2025-05-14 - Repository Branding and Documentation Navigation
**Learning:** Centering the repository logo in the README using HTML `<p align="center">` tags improves visual hierarchy and branding. Using relative paths instead of absolute GitHub URLs for internal links ensures that documentation remains functional and consistent across forks, branches, and local clones, significantly improving Developer Experience (DX).
**Action:** Always center the main logo at the top of the README and prefer relative paths for all internal repository links in documentation files.
