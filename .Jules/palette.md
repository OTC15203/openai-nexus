# Palette's Journal - UX & Accessibility Learnings

## 2025-05-14 - [Relative Navigation & Doc Accuracy]
**Learning:** In technical SDK repositories, Developer Experience (DX) is a critical part of UX. Converting absolute repository URLs to relative paths ensures that internal navigation works seamlessly across different environments (local IDEs, forks, branches). Additionally, ensuring that troubleshooting guidance for technical directives (like `#:property`) is syntactically accurate prevents friction for developers using standalone sample features.
**Action:** Always prefer relative paths for internal repository links in Markdown and double-check technical directive syntax against the actual implementation or validated examples.
