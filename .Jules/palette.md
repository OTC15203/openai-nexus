## 2025-06-05 - Relative Internal Navigation

**Learning:** Using absolute GitHub URLs (blob/main) for internal repository navigation in READMEs breaks the user experience when browsing forks, branches, or local clones, as it redirects users back to the original repository's main branch.

**Action:** Always prefer relative paths (`./path/to/file`) over absolute GitHub URLs for internal repository links to maintain navigation context across different environments.
