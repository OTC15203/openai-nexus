# Palette's Journal - UX/DX Learnings

## 2025-05-22 - DX: Repository Branding and Navigation Portability
**Learning:** Technical SDK repositories often overlook the "Developer Experience" (DX) of their documentation. Using absolute GitHub URLs for internal links breaks navigation when working in forks, branches, or local environments. Consistent repository branding (logos) helps with orientation and project identity.
**Action:** Always prefer relative links for internal documentation and ensure the repository logo is prominently and consistently displayed in main README files using accessible HTML.
