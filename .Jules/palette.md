## 2025-05-14 - Consistency in Documentation Directives
**Learning:** In documentation that uses custom directives (like `#:property` for .NET single-file apps), consistency between the guide's troubleshooting section and the actual examples is crucial for DX. However, project-specific standards (e.g., `Key=Value`) must be strictly followed even if common patterns might suggest otherwise.
**Action:** Always verify custom directive formats against the existing codebase before suggesting or applying changes.
