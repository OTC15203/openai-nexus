# Palette's Journal - UX & Accessibility Learnings

## 2025-05-14 - [Directives Accuracy in Documentation]
**Learning:** Incorrectly documented metadata directives (like `#:property`) in code snippets can lead to frustrating build errors for developers trying to follow quickstart guides. The `.NET 10` standalone file feature is particularly sensitive to the `Key=Value` format.
**Action:** Always verify the syntax of custom directives in documentation against the actual implementation or updated guides to ensure a smooth "first-run" experience.
