# Palette's Journal - UX & Accessibility Learnings

## 2025-05-14 - Repository Branding and Internal Navigation
**Learning:** For SDK repositories, the documentation IS the UI. Centering the project logo and using relative links for internal resources significantly improves the "local-first" developer experience and branding consistency.
**Action:** Always use centered <img /> tags for branding in READMEs and prefer relative paths for all internal repository references to maintain functional navigation across forks and local clones.
