# Palette's Journal - UX & Accessibility Learnings
## 2026-07-04 - Correcting .NET 10 Directive Syntax Documentation
**Learning:** Documentation suggested a space-separated format for the `#:property` directive, while the .NET 10 SDK and existing codebase use a `Key=Value` format. Misleading syntax instructions in troubleshooting guides significantly degrade the Developer Experience (DX).
**Action:** Always cross-verify documentation troubleshooting tips against actual successful code patterns in the repository to ensure accuracy.
