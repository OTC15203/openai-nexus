# Palette's Journal - UX & Accessibility Learnings

## 2025-05-14 - Consistency in C# Documentation Snippets
**Learning:** For technical documentation involving executable snippets (like .NET 10 single-file apps), Developer Experience (DX) is a critical component of UX. Ensuring all samples follow a consistent configuration pattern (like `PublishAot=false`) prevents runtime failures that frustrate users. Additionally, the format of metadata directives (like `#:property Key=Value`) must be correctly documented to avoid confusion.
**Action:** When working with documentation-heavy SDKs, audit the snippets for consistent configuration and ensure the "Troubleshooting" or "Getting Started" guides accurately reflect the required syntax.
