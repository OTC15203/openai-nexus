## 2026-05-29 - [Branding and Navigation Consistency]
**Learning:** In technical SDK repositories without a web UI, UX improvements focus on Developer Experience (DX): repository branding (using `eng/OpenAI.png`), documentation accessibility (descriptive alt-text), and relative navigation links.
**Action:** When working on SDK documentation, ensure brand assets are centered and accessible, and prioritize relative links over absolute GitHub URLs for better navigation in local or forked environments.
