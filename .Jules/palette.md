## 2025-05-14 - [README Branding and Navigation]
**Learning:** In technical SDK repositories without a web UI, UX improvements focus on Developer Experience (DX). This includes repository branding (using `eng/OpenAI.png`), documentation accessibility (descriptive alt-text), and relative navigation links which ensure functional navigation across forks and branches.
**Action:** Center repository logos at the top of READMEs and prefer relative paths for internal documentation links.
