# Palette's Journal - UX & Accessibility Learnings

## 2026-07-06 - Correcting DX Documentation for .NET 10 Samples
**Learning:** In technical SDK repositories, Developer Experience (DX) is UX. Misleading documentation about metadata syntax (like the `#:property` directive) causes immediate friction and build failures for new users.
**Action:** Always verify that "Troubleshooting" sections in documentation match the actual implementation and sample code in the repository.
