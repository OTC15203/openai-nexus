# Palette's Journal - UX & Accessibility Learnings

## 2026-06-21 - [DX is UX: Fixing documentation directives]
**Learning:** In technical SDKs, the "user interface" is the documentation and samples. Inconsistent or incorrect metadata directives (like #:property) in samples create a broken first impression and hinder developer success.
**Action:** Always verify documentation Troubleshooting guides against actual project requirements and ensure all sample snippets follow the corrected pattern for a "just works" experience.
