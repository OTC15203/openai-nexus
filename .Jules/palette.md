## 2025-05-15 - DX and Documentation Accessibility for SDKs
**Learning:** In technical SDK repositories without a web UI, User Experience is synonymous with Developer Experience (DX). Enhancing the README with visual branding and accessible, functional navigation links significantly improves the first-impression and usability of the library.
**Action:** Prioritize relative links over absolute GitHub URLs to ensure documentation remains functional in mirrors and forks, and use centered branding with alt-text for a professional, accessible landing page.
