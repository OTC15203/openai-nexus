## 2026-06-25 - Relative internal navigation and documentation accuracy
**Learning:** Using relative internal navigation links in technical documentation improves DX by maintaining context in local environments and forks. Correcting metadata syntax (e.g., #:property format) prevents developer friction during setup.
**Action:** Use relative paths with './' prefix for internal repo links and verify metadata syntax against the latest SDK requirements.
